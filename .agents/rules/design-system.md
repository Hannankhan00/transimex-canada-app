# MANDATORY DESIGN SYSTEM INSTRUCTION: Institutional Logistics

BEFORE writing or modifying any UI component, page, style, layout, color, typography, or component in this repository, you MUST ALWAYS consult and adhere strictly to `design.md`.

## Core Directives from `design.md`:
1. **Brand Identity:** Corporate Modern for Transimex Canada Logistics. High-clarity, institutional, dependable.
2. **Color Palette:**
   - Background Canvas: `#f9f9ff` / `#f5f7fa`
   - Primary Surface / Cards: `#ffffff` with subtle 1px border (`#E2E8F0`) or soft ambient shadow `rgba(0,0,0,0.05)`
   - Fixed Sidebar: Navy Blue `#0b2545` (width: 260px)
   - Primary Functional / Active Highlight: Red `#d21f27` (hover: `#ab0015`)
   - Text Primary: `#111c2d` / `#1e293b`
   - Text Muted: `#64748B`
3. **Typography:**
   - Headlines / Display / Titles: **Playfair Display** (`font-serif`)
   - Body, UI, Labels, Data Tables: **Inter** (`font-sans`)
4. **Shapes & Radius:**
   - Base inputs & buttons: `0.5rem` (`rounded-lg` / `rounded-md`)
   - Primary cards & containers: `1rem` (`rounded-2xl` / `rounded-xl`)
   - Status Chips & Badges: Full pill (`rounded-full`)
5. **Component Rules:**
   - Active sidebar item: 4px Red (`#d21f27`) left border + 10% white opacity background on Navy.
   - Primary Buttons: Solid Red `#d21f27`, White text, Base radius `0.5rem`.
   - Secondary Buttons: Solid Navy `#0b2545` or Outlined Red.
